Jira Bağlantısı

Panel jira.thy.com'a bağlanmak için Personal Access Token (PAT) ister. Token yalnızca bu oturumda bellekte tutulur, diske kaydedilmez — uygulamayı her açtığınızda yeniden istenir.

Token oluşturma: jira.thy.com → sağ üstte profil → Profile → Personal Access Tokens → Create token
